# Findex - Lazy Text Processor (Lab 01)

## Інструкція з запуску
Для запуску тестів токенізатора:
`PYTHONPATH=src uv run pytest tests/`

Для запуску збору статистики та порівняння пам'яті:
`PYTHONPATH=src uv run python src/findex/stats.py`

Проєкт для потокової обробки великого текстового корпусу з мінімальним споживанням оперативної пам'яті за допомогою ітераторів та генераторів (`yield`).
Корпус для тестування: дамп статей української Вікіпедії (~50 МБ).

## Правила токенізації
- **Unicode-нормалізація:** NFC (зведення складених символів до єдиного, наприклад `e` + `´` -> `é`).
- **Регістр:** Усі слова зведені до нижнього регістру через `casefold()`.
- **Фільтрація:** Зберігаються літери, цифри, а також дефіси та апострофи всередині слів (наприклад, `комп'ютер`, `будь-ласка`). Пунктуація видаляється.

### Аналіз використання пам'яті
У "жадібному" підході пам'ять витрачається на завантаження всього масиву тексту через `f.read()` та створення гігантського списку всіх знайдених токенів одночасно через метод `re.findall()`. 

У "лінивому" конвеєрі ми читаємо файл по одному рядку (`for line in f`), а токенізатор віддає слова по одному через `re.finditer()`. У пам'яті одночасно перебуває лише один рядок тексту, а єдина структура, яка накопичує дані і споживає пам'ять — це агрегатор `Counter` (словник частот термів).
