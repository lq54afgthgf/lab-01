# Лаб 4. Типи, тести, пакування і CLI

[![CI](https://github.com/Tserelenko/findex/actions/workflows/ci.yml/badge.svg)]

## Опис
Четвертий етап розробки пошукового рушія `findex`. Проєкт перетворено на повноцінний незалежний Python-пакет із підтримкою суворої типізації (`pyright strict`), розширеним тестовим покриттям на `pytest` (включно з property-based тестами через `Hypothesis` та бенчмарками), а також сучасним CLI-інтерфейсом на базі `typer` та `rich` з підтримкою `logging` у `stderr`, структурованого виводу `--json` у `stdout` і вивіреними кодами виходу при помилках.

---

## Архітектура та інструменти якості
1. **Типізація (`pyright strict`):** Усі публічні модулі (`src/findex/`) повністю анотовані. Протокол `Scorer` реалізує статичний duck typing, параметри `engine` та `scorer` типізовані через `Literal`, а генератори явно позначені як `Iterator` або `Iterable`.
2. **Тестування (`pytest` + `Hypothesis` + `pytest-cov`):** 
   - Понад 45 модульних, інтеграційних та property-based тестів.
   - Завдяки `Hypothesis` перевірено три інваріанти:
     1. `load(save(index))` є ідемпотентним (збереження та завантаження відновлюють ідентичний індекс).
     2. Постінги в індексі завжди відсортовані за `doc_id`.
     3. Операція `merge` математично збігається з перетином/об'єднанням множин (`set`).
3. **CLI та `rich` (`src/findex/cli.py`):**
   - Підкоманди: `findex index` (із живим прогрес-баром через `rich.live`), `findex search` (табличний вивід результатів або прапорець `--json` для пайплайнів) та `findex stats`.
   - Рівні деталізації логування: `-v` (INFO) та `-vv` (DEBUG), які пишуться виключно в `stderr`.
   - Очікувані помилки (відсутній індекс, невалідний запит) виводять зрозуміле повідомлення без стека викликів і завершують роботу з ненульовим кодом.

## Інструкція зі встановлення та запуску

**Встановлення пакета з віддаленого репозиторію або локально через `uv`:**
```bash
# Встановлення у глобальне середовище в один рядок
uv tool install .

# Або запуск безпосередньо з розробницького середовища
uv run findex --help
```

**Приклади використання CLI:**
```bash
# 1. Побудова індексу з індикатором прогресу rich
uv run findex index data/ --out index.bin

# 2. Пошук із виводом у вигляді гарної таблиці rich
uv run findex search index.bin "були AND населення" --scorer bm25 --top-k 5

# 3. Пошук із перенаправленням сирих даних у JSON (для скриптів)
uv run findex search index.bin "київ AND україна" --scorer bm25 --json > results.json
```
