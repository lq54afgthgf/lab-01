# Лаб 6. Асинхронний краулер: asyncio

## Опис завдання
**Що вивчаємо:** Асинхронне програмування (`asyncio`); кооперативна багатозадачність та Event Loop; робота, обмежена вводом-виводом (I/O-bound); мережеві запити через `httpx`; механізми повторних спроб (exponential backoff та jitter); парсинг вебсторінок; правила "ввічливого" скрапінгу та обробка `robots.txt`.

**Що зроблено в межах проєкту (Асинхронний краулер):**

1. Реалізовано асинхронний веб-краулер з використанням `asyncio` та `httpx` для неблокуючого збору сторінок в один потік.
2. Реалізовано обмеження кількості одночасних запитів на окремий домен (політика ввічливості) для контролю навантаження на цільовий хост.
3. Додано підтримку прапорців `--concurrency`, `--max-pages` та `--allowed-domains` для гнучкого налаштування CLI-команди краулінгу.
4. Налаштовано розумну функцію `fetch` із `asyncio.timeout` та автоматичною обробкою збоїв (HTTP 429, 5xx) через механізм повторних спроб exponential backoff із jitter.
5. Створено кастомний `RobotsCache` для автоматичного завантаження, розбору та суворого дотримання правил `robots.txt`.
6. Додано збереження зібраних документів у потоковий формат `.jsonl` та адаптовано старий код `corpus.py` для безшовної зворотної сумісності з попередніми `.txt` файлами.
7. Зібрано та проаналізовано метрики швидкодії (швидкість завантаження сторінок/сек, Wall Time, Peak RSS) для різних рівнів concurrency (1, 5, 20).

---

**Дозвіл на краулінг:**
Цільовий сайт `http://quotes.toscrape.com/` є публічною пісочницею, спеціально створеною для тестування скрапінгу та краулінгу. Дозвіл на автоматизований збір даних є явним.

### Бенчмарки (max-pages: 200)

| Concurrency | Wall Time (s) | Pages/sec | Errors | Peak RSS (MB) |
|---|---|---|---|---|
| 1  | ~104.7 | 1.91 | 0 | 8.68  |
| 5  | ~50.7  | 3.94 | 0 | 13.53 |
| 20 | ~50.7  | 3.94 | 0 | 32.42 |

### Інструкція з запуску для перевірки

**1. Запуск краулера (збір сторінок у JSONL)**
`bash`
uv run findex crawl http://quotes.toscrape.com/ --max-pages 200 --concurrency 5 --out data/crawl.jsonl

**2. Побудова індексу зібраних даних(Програма автоматично розпізнає формат .jsonl і збереже зворотну сумісність для старих .txt файлів)**
`bash`
uv run findex index data/crawl.jsonl index.bin

**3. Виконання пошуку по зібраних цитатах**
`bash`
uv run findex search index.bin "einstein"
